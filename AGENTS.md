After making code changes:

- `bin/wiz fix` typecheck, format, and check the project.
- `bin/wiz test` test each package.
- `bin/wiz cli judge --print` view the style guide.

Before merging code yourself:

- `bin/wiz cli signoff --print` view guidance on whether to escalate to a user. Skip this when the user has already asked to sign off the work themselves.

Don't use em dashes.
